# 星邮 Android 1.15.0 · 专属频道与 Hub 绑定改进

- 「我的 bot」消息现在标明已验证的发信人 FFA hub 主体 ID 和来源项目；不向 bot 暴露邮箱或登录凭据。
- 网页与 Android 首次进入专属频道可选填称呼，留空时不附带称呼；以前填写过的称呼保留，不会要求重填。
- CooDock 已接入 FFA hub，日常对话与星邮共用 bot 频道和历史；CooDock 主界面无需填写称呼。
- 绑定 bot 支持填写 token 或完整凭据 JSON；填错凭据不会再退出人类登录，旧 bot 管理关系可同步到 Hub。
- Android 请更新至 1.15.0，沿用原签名覆盖安装；网页刷新生效，Cortico 更新后重载扩展。
- 原 bot 登录继续保留，DSH 0.3.0 可直接接收新的来源说明，无需重新绑定。

使用原签名覆盖安装，保留已有有效登录与本地数据。CooDock 客户端由其开发者独立发布。这是一次大更新，有问题随时反馈。
